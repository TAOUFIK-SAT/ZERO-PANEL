# ZERO-SAT PRO PANEL (Enigma2 Python 3.12, 3.11 & 2.7)

بانل إنيغما 2 الاحترافي لإدارة وتثبيت كافة الإضافات وسيرفرات IPTV وبوابات MAG/Stalker ومحاكيات التشفير وملفات القنوات.

## 🚀 التثبيت المباشر عبر Telnet / PuTTY من GitHub:
```bash
wget -q "--no-check-certificate" https://raw.githubusercontent.com/TAOUFIK-SAT/download-plugins/main/ZERO-PANEL/installer.sh -O - | /bin/sh
```

## 💻 التثبيت المحلي (Local Mode):
```bash
git clone https://github.com/TAOUFIK-SAT/download-plugins.git
cd download-plugins/ZERO-PANEL
chmod +x installer.sh
./installer.sh
```

## 📁 المسار في الرسيفر:
`/usr/lib/enigma2/python/Plugins/Extensions/ZeroSatPanel/`
